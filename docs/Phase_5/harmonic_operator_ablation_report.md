## 1. 对象与结构发现(权威 run 前机制测试,预注册阶段)

step 链实测:collide(含 **dispersion 修正,碰撞内**)→ stream → 壁 callback →
**声学相位修正(对角+高模)** → **双调和滤波(0.0065×1)**。合同 §7.3 的「壁后谱修正」
=声学相位修正族 + 滤波。

**结构发现(2026-07-30,权威 run 前;测试钉死)**:声学相位修正族在 G2 rig 几何+冻结配置上
**按构造恒等**——(1) 对角支要求 kx、ky 同时非零且 laplacian<0.01926,48×8 与 16×4 上
均为 **0 个合格模**(最小对角 laplacian ~0.63);(2) 高模支因 `high_mode_factor=1.0` 且
`high_mode_diagonal_factor=1.0` 直接早退。恒等算子不可能生成/选择性放大/压低谐波——
对该算子族 §7.3 结论是**精确的**,前提是恒等性被证明而非默认:故 v1 消融列不以平凡零差
过门,而是转为 **S6 字节级恒等行**(q/p 序列 max|diff| 必须精确 ==0.0,任何未来阈值/因子/
几何变更重新激活算子即在 S6 与机制测试双重证伪)。由此本 rig 上唯一**活跃**的全局 FFT
谱算子=碰撞内 dispersion 修正(P4-1 缝注入嫌疑族)——非 §7.3 壁后算子(属 G0 标定输运
闭合的一部分),以 v4 诊断列双频归档其谐波敏感性,不参与判门。
