## 1. 目标与非目标

### 1.1 目标

1. 在已解析的 DC 热基态上构造完整离散时间推进的局部切线。
2. 用该切线复现现有 WP4-TAN 结果，证明切线实现覆盖了完整动力学链。
3. 在保持同一热基态和同一观察量的条件下，逐块冻结基态依赖，定位负趋势来自哪个 LBM 内部环节。
4. 区分单一主导项、多个模块耦合和仍未闭合三种结果。

### 1.2 非目标

- 不把消融结果直接解释为真实 thermophone 的物理机制。
- 不重新调整 dx、dt、tau、色散因子、滤波强度或热流导出系数。
- 不用新的参数拟合强行恢复 QS-1 或 1D 参照。
- 不把 TAN 称为“完整 Jacobian”；TAN 是多微幅值外推得到的数值方向切线，本文规划的是覆盖完整一步算子的切线模型。
- 不改变 Phase_5 已冻结 Gate、生产状态和论文主结论。

## 3. 为什么采用矩阵无关 Jacobian

权威网格的离散状态约为

\[
N=96\times8\times(37+37)=56832.
\]

直接保存 `N×N` 双精度矩阵约需 26 GB，若使用复数则约 52 GB，且大部分元素不会被单独使用。因此不显式生成稠密矩阵，而只计算 Jacobian 对当前扰动向量的作用。

令完整一步推进为

\[
x_{n+1}=F(x_n,T_w),\qquad x=(f,g).
\]

在热基态 `x_bar`、平均壁温 `T_bar` 上，切线满足

\[
\delta x_{n+1}=J(\bar x)\,\delta x_n+B(\bar x)\,\delta T_w.
\]

矩阵无关中心差分实现为

\[
Jv+B\eta\approx
\frac{F(\bar x+h v,\bar T+h\eta)-F(\bar x-h v,\bar T-h\eta)}{2h}.
\]

这里“完整”指碰撞、迁移、热壁、声学修正、滤波和观察量全部进入一步算子，而不是把巨大矩阵写入磁盘。

## 4. 实施流程

### 4.1 步骤 A：保存完整 DC 热基态

在 `scripts/phase5_g4a_dc_basestate.py::run_tent` 的 DC settle 结束处，增加只读快照能力，至少保存：

- `f_bar`、`g_bar`；
- `theta_wall_bar`、沉带温度和热带/沉带位置；
- 求解器声学相位修正使用的参考三元组 `(rho_ref, u_ref, theta_ref)`；
- 若未来配置启用 pressure-memory trace，连同上一时刻压力场一起保存；
- 一步算子各阶段的基态中间量：碰撞后、迁移后、边界后、声学校正后和滤波后状态。

基态必须继续满足现有合法性门：

- 每周期 stationarity 不超过 `1e-3`；
- 实测 `Theta_DC` 与目标偏差不超过 `1e-2`；
- 质量、DC 能量闭合和双柱重复性沿用 G4a/TAN 现有门。

另外记录

\[
r_F=\frac{\|F(\bar x,\bar T)-\bar x\|}{\max(\|\bar x\|,\epsilon_{mach})}.
\]

`r_F` 只用于确认 settle 是否充分，其权威阈值必须在 smoke 后、正式 run 前冻结，不得按热态结果逐点调整。

### 4.2 步骤 B：把一步推进拆成可审计阶段

保持生产顺序逐字一致：

\[
F=H\circ A\circ B\circ S\circ C,
\]

其中：

| 符号 | 模块 | 当前入口 |
|---|---|---|
| `C` | 宏观量恢复、平衡分布、SMRT 碰撞、应力/热流和能量修正 | `core/collision_smrt.py::collide_fg` |
| `S` | pull streaming | `core/streaming.py::pull_stream_fg` |
| `B` | 热带与沉带质量中性重构，同时记录精确能量交换 | `boundary/wall_thermal_mass_neutral.py`、`make_energy_audited_band` |
| `A` | 对角低模声学相位修正及配置允许的其它声学校正 | `core/solver.py::_apply_*acoustic_phase_correction` |
| `H` | seam-aware 保守双调和滤波 | `core/solver.py::conservative_biharmonic_filter` |

切线模块应调用与生产求解器相同的阶段函数，不复制一份独立“近似求解器”。任何阶段顺序变化都视为仪器变化。

### 4.3 步骤 C：实现阶段级 JVP

每个阶段提供“基态 + 扰动 → 输出扰动”的接口。中心差分默认使用宏观归一化后的三档步长：

\[
h\in\{10^{-4},5\times10^{-5},2.5\times10^{-5}\}.
\]

扰动归一化采用

\[
\max\left(
\frac{|\delta\rho|}{\rho_0},
\frac{|\delta\theta|}{\theta_0},
\frac{|\delta u|}{c_0}
\right)=1.
\]

若默认三档在冷态 smoke 中没有出现中心差分的二阶收敛区，允许只在冷态 smoke 上扫描 `10^-3` 至 `10^-7`；选择连续三档稳定区后，在任何热态结果产生前写入配置并冻结。

必须避免以下实现错误：

- 每个时间步重新 settle 基态；
- 在 `+h/-h` 两支中使用不同缓存或不同参考态；
- 忘记热壁输入导数 `B eta`；
- 只线性化碰撞而遗漏边界和声学修正；
- 用有限 AC 生产轨迹代替固定基态上的切线推进。

### 4.4 步骤 D：推进完整切线并读取 `Y_g`

以 10 kHz 正弦 `delta T_w` 驱动切线状态，采样和拟合窗口完全复用 WP4-TAN：

1. 从 `delta f=delta g=0` 开始；
2. 每步应用完整 JVP；
3. 对热带边界前后总能量差做同样的切线读出；
4. 用现有多谐波拟合器提取壁温和热流的 1f 复幅值；
5. 形成 `Y_g`、`D_OP`、`d_OP`、`Delta_phi_OP`。

## 5. 完整切线的硬验证

消融前必须依次通过以下检查：

| 编号 | 检查 | 通过条件 | 失败处理 |
|---|---|---|---|
| V0 | 基态合法性 | 沿用 TAN 的 stationarity、state-match、SNR 和 DC 闭合门 | 回到 settle/快照，不进入切线 |
| V1 | `+h/-h` 对称性 | 奇组合稳定；偶组合随 `h^2` 衰减至数值底 | 检查归一化、缓存和边界输入 |
| V2 | JVP 步长稳定性 | 三档外推后的 `Y_g` 对步长选择不敏感 | 在冷 smoke 重新冻结步长窗 |
| V3 | 冷态回归 | 与现有冷态增量导纳在拟合不确定度内一致 | 检查输出切线和时间相位 |
| V4 | 热态身份 | `Theta=0.05/0.10` 的 `d_OP` 与归档 TAN 均相差不超过 `0.2 pp` | 标记切线未验证，禁止消融 |
| V5 | 切线守恒 | 无输入时质量切线为数值零；输入时热带/沉带能量账闭合 | 检查边界和 `delta_G` 切线 |

只有 V0–V5 全部通过，才能把该实现称为“完整热基态切线”。

## 6. 粗粒度逐块消融

### 6.1 核心原则

消融不是删除整个物理模块，也不是重新跑一个不同基态。正确做法是：

1. 始终使用同一份热基态 `x_bar`；
2. 完整变体使用该阶段的热态导数 `D F_i(z_i^hot)`；
3. 单项消融只把选中阶段替换为冷态或冻结参考导数；
4. 其它阶段仍使用热态导数；
5. 同时保留冷态与热态阶段中间快照，保证替换位置可审计。

这种混合切线是诊断工具，不代表一个新的完整物理模型。

### 6.2 第一轮消融矩阵

| 编号 | 消融块 | 冻结内容 | 优先级 | 主要问题 |
|---|---|---|---:|---|
| A0 | 完整热态切线 | 无 | — | TAN 身份基线 |
| A1 | 声学相位参考态 | 把相位修正算子的 `(rho_ref,u_ref,theta_ref)` 固定为冷态值 | 1 | 负趋势是否来自工作点相关数值相位校正 |
| A2 | 质量中性热壁 | 把壁面重构的基态导数替换为冷态版本，仍保留同一壁温输入 | 2 | 热壁密度响应/能量重钉扎是否主导 |
| A3 | 宏观恢复与平衡分布 | 冻结热态 `rho/theta/u` 对 `f_eq/g_eq` 的交叉导数 | 3 | 高阶热平衡矩是否主导 |
| A4 | 应力闭合 | 冻结 `rho*theta` 前因子及 trace/deviatoric 热态依赖 | 4 | 热态应力重构是否主导 |
| A5 | 热流与能量修正 | 冻结中心热流重构、`f/g` 分配和 `delta_G` 热态依赖 | 5 | 能量通道是否主导 |
| A6 | 线性阴性对照 | 对 streaming 和固定系数 filter 做等价替换 | 控制 | 应接近数值零；否则消融实现有误 |

Route-B 当前的 `tau21/tau22/tau32`、色散系数和热流因子由 frozen mapping 给定，并不随局部温度更新。因此第一轮不得把不存在的 `d tau/dT`、`d k/dT` 或 `d mu/dT` 写成 LBM 内部消融项。这些导数只适用于未来显式温变物性的连续体或 Route-A 模型。

## 7. 细粒度消融

只细分第一轮中影响最大的一个或两个模块。

### 7.1 A1：声学相位参考态

依次比较：

1. 仅冻结 `theta_ref`；
2. 仅冻结 `rho_ref`；
3. 冻结完整参考三元组；
4. 保留热态参考三元组，但冻结由其生成的 operator；
5. 关断修正只作附加敏感性，不作为同基态主消融，因为它会改变认证仪器。

若 1–4 中任一项关闭大部分差异，应优先按“参考态相关数值校正”解释，而不是热声新物理。

### 7.2 A2：质量中性热壁

依次冻结：

1. `rho_w` 对 streamed populations 的导数；
2. `feq_w/geq_w` 对壁温的导数；
3. interior non-equilibrium copy 的导数；
4. 质量/动量平衡增量清除项；
5. 内能目标与 `g` 均匀重钉扎项；
6. 能量簿记输出映射。

质量中性、`u=0` 和壁温钉扎在每个变体中仍必须成立；否则该变体无解释资格。

### 7.3 A3：宏观恢复与平衡分布

依次冻结：

1. `u=j/rho` 中的基态密度交叉项；
2. `theta=2E/[(D+S)rho]` 中的基态密度交叉项；
3. `f_eq` 中二至四阶温度矩的热态导数；
4. `g_eq` 中 `rho*theta` 内能零矩及其高阶矩导数；
5. central-moment 变换对基态速度的导数。

### 7.4 A4：应力闭合

依次冻结：

1. trace 通道的 `rho*theta` 前因子；
2. trace 通道的速度散度导数；
3. deviatoric 通道的 `rho*theta` 前因子；
4. 应变率导数；
5. 固定谱修正仅作阴性对照。

### 7.5 A5：热流与能量修正

依次冻结：

1. central energy flux 对基态速度的导数；
2. `f/g` 热流分配的基态依赖；
3. minimum-norm moment reconstruction 的基态速度依赖；
4. `delta_G=E_before-E_mid` 能量修正导数；
5. 导出端 Galilean correction 只在观察量实际使用该通道时检查；当前 `Y_g` 主读数来自热带精确能量簿记，不应把导出热流矩误当主观察量。

## 8. 判读规则

### 8.1 单项贡献

对每个变体报告

\[
S_i=d_{OP}^{(-i)}-d_{OP}^{full},
\]

以及相对 QS-1 差异的闭合比例

\[
C_i=1-\frac{|R_{dyn}^{(-i)}|}{|R_{dyn}^{full}|}.
\]

`C_i=1` 表示该消融把 dynamic–quasi-static discrepancy 完全闭合；`C_i<0` 表示差异反而扩大。`C_i` 只用于诊断贡献，不是统计归因比例。

建议在预注册中采用以下解释线：

- 同一模块在 `Theta=0.05` 和 `0.10` 均闭合至少 50% 差异，并使结果稳定向 QS-1 方向移动：主要候选；
- 单项不足 50%，但两个已预注册模块的组合稳定跨过 50%：耦合候选；
- 只有一个工作点有效或方向相反：工作点局部敏感性，不称主机制；
- 所有单项和有限组合均无显著作用：保持 `MECHANISM_NOT_CLOSED`。

### 8.2 组合消融

只对单项贡献最大的两个或三个模块做两两组合，不做全组合穷举。组合贡献若明显大于两个单项之和，记录为协同；若明显小于，记录为重叠。组合阈值与比较公式必须在组合 run 前冻结。

### 8.3 结论边界

| 结果 | 可以说 | 不可以说 |
|---|---|---|
| A1 主导 | 当前 LBM 的符号差异主要关联参考态相关声学校正 | 真实空气存在同一机制 |
| A2 主导 | 当前认证壁的局部切线是差异主要来源 | 质量中性壁普遍错误 |
| A3/A4/A5 主导 | 当前离散碰撞/能量链中的指定导数项控制差异 | 已发现真实 thermophone 新物理 |
| 组合主导 | 差异由多个内部模块耦合产生 | 任一单项是唯一原因 |
| 未闭合 | 已排除所测试切线块 | 不存在其它数值或物理机制 |

即使碰撞热力学项主导，也仍需独立二维连续体切线或实验，才能升级为真实物理机制声明。

## 9. 运行矩阵与停止条件

### 9.1 最小运行矩阵

先只做 `Theta_DC={0,0.05,0.10}`：

1. 完整切线 3 点；
2. A1–A5 五个单项消融，各 3 点；
3. A6 阴性对照 3 点；
4. 只对前两名做一个两两组合，3 点。

最小权威矩阵共 24 个工作点变体。开发阶段先使用现有 `tan_smoke` 小网格，完整身份通过后才进入权威网格。机制候选确定后，再用 `Theta_DC=0.02/0.075` 做趋势复核，不在第一轮扩张矩阵。

### 9.2 硬停止条件

出现以下任一情况立即停止，不解释消融结果：

- 完整切线未通过 V0–V5；
- `+h/-h` 两支使用了不同缓存或不同参考算子；
- 阴性对照产生与主要候选同量级的偏移；
- 为获得符号翻转而逐点调整步长、拟合窗或模型系数；
- 消融破坏质量中性、壁温钉扎或能量守恒；
- 生产求解器行为发生变化但未触发合同 §23 定向复验。

## 11. 测试要求

实现前先写以下失败测试：

1. 已知线性映射的 JVP 精确恢复；
2. 已知二次非线性映射的中心差分二阶收敛；
3. streaming 与固定滤波的热/冷导数相同；
4. 壁面切线保持零质量增量、零壁速和目标壁温增量；
5. 碰撞切线保持质量、动量和总能量守恒；
6. A1–A5 每个变体确实改变被指定的导数块，且不改变其它块；
7. A6 阴性对照在合成夹具上为数值零；
8. smoke 完整切线能够对有限差分 TAN 给出正确方向；
9. 无效变体名、未冻结步长窗和缺失基态快照必须失败退出。

权威 run 前还需完成：相关单元测试、现有 WP4 测试、G4a 基态测试和文档校验。若修改生产碰撞、热壁、声学修正或滤波函数本身，按合同 §23 扩大回归范围。

## 13. 推荐执行顺序

1. **预注册**：冻结快照字段、JVP 步长选择规则、A0–A6、V0–V5 和判读阈值。
2. **单元测试**：先完成合成映射、守恒和非退化测试。
3. **冷态 smoke**：选择并冻结 JVP 稳定步长窗。
4. **热态 smoke**：验证完整切线能追随有限差分 TAN 方向。
5. **权威完整切线**：先通过 TAN 身份门。
6. **粗粒度消融**：一次只替换一个导数块。
7. **细粒度与有限组合**：只追踪第一轮的前两名。
8. **趋势复核**：候选确定后再加入 `Theta=0.02/0.075`。
9. **报告**：明确区分 LBM 内部数值来源、模型机制和真实物理三层结论。

## 14. 一句话验收标准

> 先用完整热基态切线在 `0.2 pp` 内复现 WP4-TAN，再在同一基态上通过预注册的单块导数替换，找出能够在两个热工作点稳定关闭大部分 dynamic–quasi-static discrepancy 的内部模块；若没有模块满足条件，则诚实保留 `MECHANISM_NOT_CLOSED`。
