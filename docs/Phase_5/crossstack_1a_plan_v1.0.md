## 1. 为什么立这个项

投稿适配评估暴露的**最大接受风险不是"缺疗法"，而是"只在自己一套栈上测过"**：全部证据来自同一冻结配置（10 kHz、dx2p6、D2Q37 + RR 闭合、一面壁 + 3 个合法变体），而论文声称的适用范围是"湿节点/逐步重钉扎家族"——这个跨度目前**只靠结构论证撑着**。

审稿人（PoF / PRE / JCP 皆然）的第一问必然是"**这是普遍陷阱还是你们代码的特性**"。1a 用最低成本回答其中一个轴：**换掉碰撞算子的结构，伪迹还在吗？**

**结果的两种走向都必须提前接受**：

- 伪迹仍在 → 普遍性从"论证"升为"实测"，可直接进论文，1b/1c 可选做；
- 伪迹消失 → 说明与 RR 闭合强相关，**论文声明范围必须大幅收窄**，且不宜急投 PRE/JCP。

## 2. 执行前必须知道的事实（已核实）

**① 仓库中不存在 BGK 或标准 MRT 碰撞算子**——`core/collision_smrt.py` 只实现 `SMRT_central_Hermite_regularized_stress` 一种。"换碰撞模型"不是配置开关，需自写算子。

**② 但自写 BGK 的成本远低于最初估计**（代码核查后修正，2026-08-14）：`equilibrium_fg`（f_eq/g_eq）与宏观恢复均已存在，BGK 本体只是

```text
f_post = f − (f − f_eq)/τ_f ,    g_post = g − (g − g_eq)/τ_g
```

约 50–100 行。真正工作量在两处：**(a)** 从 τ 反算其自身输运（ν、α），把同一个物理问题正确摆上去；**(b)** 冷态验证（须复现 Phase_1 半空间导纳解析解，否则结果无论正负都不可信）。诊断级实现现实估计 **2–4 天**，非最初口头说的"一周以上"。

**③ 开源生态里没有现成可用的对照栈**（2026-08-14 检索）：社区目录中标称支持 thermal 的成熟代码（OpenLB / Palabos / TCLB / VirtualFluids / ch4-project / LBSim）其热模型主流是 **Boussinesq / 被动标量**——温度是独立输运标量、壁面直接写 `g = w_i·T_w`，**没有 ρ 因子**，因此天然不会出现本伪迹，null 结果无判别力（同"D2Q9 被动标量"陷阱）。GitHub `polyatomic lattice boltzmann` 命中 **0**，`compressible lattice boltzmann solver` 仅 3 个近乎无人使用的仓库。唯一像样的同族替代是 `zhulianhua/dugksFoam`（DUGKS，98 star，天然含内能自由度），但属跨方法对照，需额外论证可比性且要引入 OpenFOAM 工具链。**结论：外部代码对本单元不可用；此项已核查，勿重复调研。**

**④ 上述 ② 与 ③ 共同决定了 §3 的顺序**：BGK 自写为主路径，配置轴降为补充。

可用的**配置结构轴**（补充路径；已在代码中实现且被校验）：

| 轴 | 生产值 | 可选值 | 结构含义 |
|---|---|---|---|
| `deviatoric_stress_policy` | `strain_rate_isotropic` | `measured` | 偏应力由应变率重建 vs 由实测非平衡矩重建——**两种本质不同的应力闭合** |
| `trace_bulk_policy` | `ghost_orthogonal_local` | `tau22`、`calibrated`、`current_zero` | 迹/体积通道被 ghost 正交清零 vs 按 τ22 弛豫——**体积黏性通道的不同处理** |
| `central_moment_closure` | `second_order` | `fourth_order` | ghost 扇区清零 vs 显式保留（**已在 ghost 扫描测过，τ=1.0 锚点可免费复用**） |

**已排除**（PROJECT_CONTEXT §3 记录的反例）：`*_laplacian` / `*_pressure_memory` / `*_two_channel` / `*_entropy_manifold` 四个 trace 变体已作反例排除，不得复活。

## 3. 分层设计与执行顺序（v1.0 修订：BGK 提为主路径）

| 层 | 内容 | 开发 | 算力 | 墙钟 | 风险 | 本次范围 |
|---|---|---|---|---|---|---|
| **1a-BGK**（主路径） | 自写诊断级 BGK 碰撞（f/g 各一个 τ），同点阵同壁同几何 | 2–4 天 | 6–8 h | **3–5 天** | 中（**主要风险=BGK 在 37 速点阵 + 本 τ 下可能失稳**，正则化本就是为稳定性引入的） | **是** |
| **1a-CFG**（补充，可并行） | 配置轴：`deviatoric_stress_policy` + `trace_bulk_policy` | 0.5–1 天（复用 ghost 扫描骨架） | 6–10 h | 1.5–2 天 | 低 | **是**（等 BGK 跑时顺手做） |
| 1a-LAT | 点阵轴：D2Q21 | 1–2 天 | 6–8 h | 2–3 天 | 中高（dx2p6 导出因子/色散修正是 D2Q37 专属，冷态基线可能失准） | 视结果 |

**为什么 BGK 优先**：① 审稿说服力最高——"换成最标准的碰撞算子，伪迹还在"一句话就能被审稿人理解并接受，而配置轴需要先解释我们自家的策略名词；② 成本经核查远低于原估（见 §2②）；③ 外部代码路线已排除（§2③），自写是唯一可行的独立碰撞对照。

**BGK 失稳时的回退路径**（预先约定，避免临场改口径）：

1. 先在**冷态**（Θ_DC=0）尝试；冷态即失稳 → 记录失稳阈值（τ 与幅值），**该失稳事实本身入报告**（"最标准的碰撞算子在本几何上不可用"是有价值的方法学记录），主路径切换到 1a-CFG。
2. 冷态稳、热态失稳 → 按 A5 χ 端点先例记档，报告失稳边界，用可存活的工作点做部分结论（若只剩 Θ=0.05 可用，则只报单点、不作双点分类）。
3. 任何情况下**不得**为让 BGK 稳定而调 dx/tau/滤波强度——那会破坏与生产栈的可比性，使整个对照失效。允许调整的只有 BGK 自身的 τ_f/τ_g（它们本就是 BGK 的自由参数），但须记录并说明其对 ν、α 的影响。

## 4. 协议（照抄 ghost 扫描，只换碰撞算子/配置轴）

- **不动的部分**：生产壁（v1.1 对称质量中性壁）、canonical 帐篷几何、10 kHz、dx2p6、切线测量链（`core/tangent_wallfix.py`）、JAB 合法性门、settle/drive 窗口。
- **变的部分**：只有碰撞算子（1a-BGK）或碰撞配置键（1a-CFG）。
- **1a-BGK 的额外前置**（不可省，否则结果不可信）：
  - 从 τ_f/τ_g 解析推出该 BGK 的 ν、α，据此确认 δ_T 与几何在物理单位上与生产栈**同一问题**（H_s/δ_T 保持 4.71；若 α 不同则需相应调 hs 行数）；
  - **冷态验证**：Θ_DC=0 下的 Y 必须复现 Phase_1 半空间导纳解析解（`reference/thermal_admittance.py`）到合理精度（建议 ≤10%，BGK 无本项目的色散/导出标定，不要求达到生产栈的精度）；未过此关则 BGK 结果不得用于任何跨栈结论。
- 网格：smoke（hs=12/nx=4）→ auth（hs=48/nx=8，唯一判决网格）；**smoke 不复现生产符号，只做机器链验证与筛查**。
- 工作点：Θ_DC ∈ {0（锚）, 0.05, 0.10}；JVP h = 5e-5（冻结值）。
- 失稳/非法变体按 A5 χ 端点先例记档剔除（`partition_ht` 同款），不判整轮失败。
- 逐例检查点 + 断点续跑；B 机按 D5-3 纪律（发跑前两机同 commit、记机器指纹、schtasks 一次性派发）。

**实现建议**：直接复制 `scripts/phase5_wallfix_ghost_relax_scan.py` 改一个 `phase5_crossstack_collision_scan.py`——它的 `scan_gas_cfg()` 就是改碰撞配置键的钩子，`partition_ht` / `classify` / 检查点逻辑可原样复用（把 `high_tau` 换成变体名即可）。

## 5. 判读线（**冻结；执行前写入 runner 常数区，先于任何变体数值**）

- **锚点门**：生产配置复现冻结 TAN 值 `d_OP = −2.8345 / −5.3171 pp`，偏差 ≤ **0.2 pp**（V4 同 caliber）。不过则整轮 `LEGALITY_FAILED`。
- **活键门（非退化对照，必设；仅对 1a-CFG）**：每个配置变体的冷态 |Y₀| 相对生产的位移必须 ≥ **1e-4**（相对）。位移低于此线 = 该开关在本 rig 上结构惰性，**该变体的 d_OP 结果无判别力，只能记档不能用作证据**——这是 Phase_3"smoke 按构造必过"的教训，必须防。（1a-BGK 不适用此门：它是不同算子而非开关，其"活性"由冷态半空间锚验证承担。）
- **1a-BGK 冷态锚门**：Θ_DC=0 的 Y 对 Phase_1 半空间解析导纳偏差 ≤ **10%**（BGK 无本项目的色散/导出标定，不要求生产级精度）。不过则 BGK 结果**不得用于任何跨栈结论**，只记录为"BGK 在本 rig 上未达可用精度"。
- **合法性门**（JAB 逐字继承）：stationarity ≤1e-3、dc_closure ≤1e-3、r_F ≤1e-5、V5 质量 ≤1e-7、V5 能量账 ≤1e-5。
- **分类**（auth 网格，主判决点 Θ ∈ {0.05, 0.10}，两点同时满足才成立）：

| 标签 | 条件 | 含义 |
|---|---|---|
| `CROSSSTACK_ROBUST` | 两点符号仍为负 且 \|Δd_OP vs 生产\| < 1.0 pp | 伪迹与该结构轴无关——**普遍性实测证据** |
| `CROSSSTACK_SENSITIVE` | 两点符号仍为负 但 \|Δd_OP\| ≥ 1.0 pp | 定量依赖该轴，声明范围需收窄并给出依赖幅度 |
| `CROSSSTACK_ABSENT` | 两点符号翻正 | 伪迹为生产闭合特有——**论文叙事需重写** |
| `CROSSSTACK_MIXED` | 两点不一致 | 记录，不作单侧结论 |

- **比值稳健性核查（不可省）**：每个变体同时报告冷态 |Y₀| 绝对值与 d_OP。**不得假设"与基态无关的乘性误差在比值里抵消"**——该假设已被 DC 臂 raw/corrected 对照证伪（残差随 Θ 单调增至 0.12 pp）。若某变体的 |Y₀| 相对生产偏移 >30%，其 d_OP 须标注"跨标定比较"caveat。

## 7. 不做 / 不得做

- 不改生产 (tau,k) 标定、不改 dx/dt、不改壁、不改滤波——本单元只动**碰撞算子本身**（BGK）或**碰撞配置键**（CFG）。BGK 自身的 τ_f/τ_g 是它的自由参数，可设但须记录其对 ν、α 的影响。
- **不为让 BGK 稳定而动生产侧任何冻结量**（见 §3 回退路径第 3 条）——那会摧毁跨栈可比性。
- 不再去调研开源替代栈：已于 2026-08-14 核查完毕（§2③），结论是生态里没有可用的热力学自洽对照实现。
- **生产 `core/collision_smrt.py` 一字不改**；BGK 走新文件，通过配置或显式参数选择。
- 不因结果"更好看"而挑变体；全部变体（含失稳、含惰性）一律记档。
- 不把 smoke 网格结果当判决。
- 不把 `CROSSSTACK_ABSENT` 读作"我们的发现是错的"——它是**声明范围的实测边界**，同样是可发表的结果，但叙事必须相应改写。
- 不把任何变体写成生产可用配置（诊断行口径，同 ghost 扫描）。
