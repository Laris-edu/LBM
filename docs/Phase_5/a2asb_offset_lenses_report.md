## 1. 问题与两条腿

系综扫描留下的等质量 Θ 偏置（R_ens(eq)=−1.653/−3.125 pp @Θ=0.05/0.10，wet 负趋势的 ~58%）：是格子本构 k=α(T)ρc_p 的**动力学表达**（换真实态本构则趋势基本归零），还是**超连续的真残差**？两条腿（皆零 LBM 算力）：QS 静态透镜族（L0=登记 QS-1 / L1=格子本构 y 分辨 / L1b=等压微扰导数敏感行 / L2=α 指数移植括号行）在系综扫描实测基态上重算；NSF 动力学腿=认证线性化热基态 NSF 仪器 + 格子本构通道（EOS 恒等式：δk|格子 = 1.04(k/T)T̂ + (k/p̄)p̂——基态与 T̂ 通道即登记 k∝T^1.04 分支（p̄/p₀ 标度），唯一新增=守恒形 p̂ 通量项，默认关闭、冷列精确惰性）。

## 3. 三层最终分账（取代系综报告 §3 的 L0 相对分账）

以**格子一致连续参照**（该介质"自己该做什么"）结账，原框架负趋势的登记结构：

1. **边界项 ~11%**（判决 run 隔离；strict-B 消除的部分）。
2. **本构质量轴（k∝ρ，已闭合）**：解释 d_OP 对系综质量的全部斜率（0.956 vs 格子预测 1.015 的 94%）与两框架差异（切线锚和解 0.006–0.007 pp）——这是"参照随质量动"的正确记账，不是残差的一部分。
3. **超连续动力学残差（本单元判定，最大单项）**：对格子一致参照 ≈ **−2.6~−3.0 pp（Θ=0.05）/ −5.0~−5.9 pp（Θ=0.10）**，质量平坦、随 Θ 近线性。静态族（四透镜）与完整连续 NSF 动力学都不复现 ⇒ 属**离散/动理学层**。方向线索（未闭合、不判决）：strict-B 权威链的壁位 FAIL（等效 Dirichlet 面位 0.93%@N64）归因于同一处近壁 3 格动理学层——Θ 线性、质量无关的特征与近壁动理学层温降误读一致，是下一个（若继续追）的首要嫌疑。

**对"换真实态本构负趋势是否消失"的登记级回答**：换本构（τ(ρ)）只有机制消除第 2 层（质量轴/系综放大）；第 3 层残差不是本构造物，**换了本构没有机制消掉它**，第 1 层归边界替换。真实空气参照下的符号级判语不变（真实空气同状态 +0.16/+0.33%）。
