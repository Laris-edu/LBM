## A. G4a:稳态 DC 基态 + 小扰动

### A.0 架构决策:帐篷(对称镜像)双带 rig(2026-07-30 预注册;含两轮探针证据)

**问题**:canonical 热沉 `T(H_s)=T_ambient`(合同 §3.3)的朴素实现=底部生产壁 + 顶部等温盖。
该几何在冻结栈上已判死(WP1-3,2026-07-22:`Y +1204%/+139°` 伪影)。**死因变量的重审
(本设计的关键输入)**:盖 rig 中壁行(row 0)与盖行(row ny−1)**跨 wrap 相邻**,两行设定点
相差全 Θ 跳变——缝上的场一阶不连续 × 闭腔累积(P4-1 族;dispersion 修正是碰撞内承重件、
不可摘除,G2-O v4 实证)。对照:G1-W 密封单带 rig 的缝上场光滑(双面同温),底板 ≤6e-10。
**⇒ 判死的是「缝上一阶场跳变 × 闭腔」,不是「两条回调行」本身。**

**解:帐篷几何**——y 周期域高 `2H_s`,**两条 v1.1 对称质量中性带(均为已认证壁,零新壁构造)**:
row 0 = 热带(膜面,`θ_w(t)` 双面对称)、row `H_s` = 环境温度带(热沉,`θ_amb` 双面对称):

- 场为连续帐篷剖面 `θ_w→θ_amb→θ_w`(仅斜率折点,**处处无一阶跳变**——与认证密封 rig
  同光滑族;WP1-3 死因变量不存在);
- 气体分成**两根独立柱**,每根=精确 canonical 问题(热面 → H_s 气层 → 等温环境面)——
  **内建重复对照**(两柱应逐位/容差一致,run 内审计行);
- v1.1 壁的能量钉扎项即热沉的物理出口(钉 θ_amb、质量中性、经 g-shift 吸收任意热流)——
  G1b 五通道终局「几何热沉把 DC 钉在边界上」的落地;
- 膜的自由双侧 `2q_g''` 因子精确映射(热带双面=膜的两个物理面,整问题、非半问题);
- `H_s` 阶梯=域高 {96,144,192} 行 ↔ `H_s`={48,72,96} 行(ny=96 域轴 G1a/G2-T 已演习);
- 实现面:`_mass_neutral_reconstruct_row0_symmetric` 泛化行号参数(默认 row 0 逐位不变)
  或探针级 roll 组合;`compose_boundary_callbacks` 组合两带。

**探针证据(2026-07-30,mini rig 32×8,冻结 dx2p6)**:
- **反对称单带变体(否弃,实测)**:双温复合行被行内碰撞逐步抹平向单温平衡(基态坍缩、
  斜率符号反转、驱动耦合仅 0.14@−176°)——**双温单行构造对碰撞不自洽**;且其 wrap 缝
  携带 2Θ 一阶跳变=WP1-3 死因同族。结构面(质量 2.8e-13、稳定、无腔伪影)正常。
- **帐篷架构探针**:见 A.0.1(权威 run 前证据行)。
