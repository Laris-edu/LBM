## 1. 协议与预注册口径

- 双分支：`1D-lbm-equivalent`（参考态常物性=路线 B 闭合）/ `1D-physical`（Sutherland 形状 T0 锚定，`air_sutherland_anchored_T0_v1`）。两分支在 T0 严格重合（线性极限简并实测：ε=0.005 时 G1 前 6 位有效数字一致、相位逐位同——Δ_prop 的参考点偏移污染为零）。
- A1 阶梯：有符号零均值热流 `q₁=ε·T0·|Y_hs|`，ε∈{0.005,0.01,0.03,0.05,0.10}；rig H=15δ、N=180（δ/12）、8 周期（settle 3/fit 5）；拟合 detrend 0（§12.2 预注册）。QoI 取壁温响应谐波（T-side；p-side 消融归 G3/WP2，见 §6 限制）。
- A2a-lite 工作点：规定壁温均值 `Θ_DC=0.05`（状态匹配按构造精确）+ 小 AC（ε=0.005），H=8δ、45 周期（settle 40）；`D_OP=|Y_inc(0.05)|/|Y_inc(0)|−1`；QS-0 用代表温度 `T̄_s=1.05T0` 与实测 `p̄` 解析求值。
- U_det 代理（WP1 级简化口径）：网格（δ/12→δ/6）+ 拟合窗（5↔4 周期）：G1 相对 ~4e-5、H2 相对 ~0.3%；U95_fit 更小。正式 U_gov 敏感性全集属 WP2+。

## 2.1 独立验证（2026-07-22，用户质询"真实空气指标测量是否正确"触发）

**D_OP：闭式热渗透率效验通过 + 表述修正。** `|Y|∝e=√(ρ·cp·k)` 闭式预测（含各 run 实测密封箱 DC 压升 `p̄/p0≈1.0248`）：lbm −1.21% vs 实测 −1.31%、phys +0.96% vs 实测 +0.87%——**双分支均钉到 0.1pp 内**；分支差闭式 +2.13pp vs 实测 +2.18pp。**表述修正**：密封测试箱压升给两分支共同 +1.24pp；恒压等效（真实器件环境）为 **lbm −2.41% vs phys −0.28%（近零）**——几何无关的可靠结论是"常物性明显变弱、真实空气几乎不变"（`ρk∝T^{k_exp−1}`，空气 k_exp≈0.89≈1 → 渗透率相消结构，合同 §2.2 预言的同族现象），**非普适符号翻转**；密封箱内呈符号翻转是几何叠加。判据不受影响（Δ_prop 几何无关）。

**H2：k 指数扫描结构性确认相消物理（ε=0.05）。**

H2 随指数**平滑单调下降、在空气指数略上方穿越近零点、越过后相位反转 ~168°**——参数化相消的典型指纹，bug 不可能产生。μ-only 对照（μ^0.76、k 常数）：H2=6.9382e-3@−88.15°，与 k_exp=0 **四位有效数字一致**→黏性通道贡献为零，效应全部来自 k(T) 导热调制。Sutherland 形状（局部指数 0.893）与幂律 k^0.893 跨函数形式一致到 3 位（4.94e-4 vs 4.93e-4）。长 settle 复测 5.16e-4（稳定 ~4%）→ ε=0.05 点非底板。**底板 caveat**：ε=0.005 的 phys H2（2.9e-5）贴近 rig 底板（~2e-5，由 H3 不随 ε² 标度暴露）——"23×"不可靠，**可靠压低倍数为 ~14×（ε≥0.03，比值稳定 0.069–0.073）**。

**统一物理图景**：空气导热指数 ≈0.9≈1 使 k(T) 效应在 DC 渗透率通道与 2f 调制通道**同时**近乎抵消密度/EOS 效应——两个"真实空气很特殊"的发现同源、自洽。

## 4. 两个选项的代价与收益

**选项 A：启动路线 A（LBM 局部 μ(T)/k(T)）**
- 收益：LBM 直接承载"真实空气有限温升非线性"表述；H2/D_OP 的绝对定量值成为 LBM 主结论。
- 代价（合同 §2.5/§2.6/附录 E）：局部/分区 `tau(T)` 闭合 + 热流导出 + 壁面全链重认证（G0-A→G1a/b-A→G2-A→G3-A，路线 B 认证不得继承）；估计 1–3 个月，6 周核心 Gate 止损线；与 WP1-3 已发现的 (tau,k) 点标定/导出窗问题叠加（k-依赖标定在 T-依赖 tau 下更复杂）。

**选项 B：维持 `ROUTE_B_MAIN + 1D_REAL_AIR_BOUNDING`（D0-3 预授权默认）**
- 收益：LBM 主线零重认证成本；论文结构不变（合同 §20：Results I=A2a/QS-1 主锚在两分支下都成立、QS-0 规则分支内有效——正是"工作点修正规则+适用边界"的可发表单元）；真实空气增量由 1D-physical 分支**定量承载**（互证仪器已建成并通过线性简并验证）；本消融的 H2 相消与 D_OP 符号翻转**本身就是论文的高价值物理结果**（"显式温变输运律的增量贡献"——路线 B 定义的隔离目标，§2.2）。
- 代价：声明按 §18 收缩——LBM 的 H2/D_OP 只能以"参考态输运闭合下"口径声明，真实空气定量值挂 1D 分支；若审稿要求 LBM 直接承载真实空气定量结论，需届时补路线 A。
