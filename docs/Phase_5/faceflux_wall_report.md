## 4. 判读

### 4.1 一个此前没有的仪器性质：faceflux 的 d_OP 是"纯气侧响应"读数

候选 B 的导纳是 `Y = G_f(θ̂_w−θ̂_1)/θ̂_w`，而 G_f 冻结、冷热相同——**注入增益在 d_OP 比值里精确相消**。faceflux 的 d_OP 因此是气柱动态传递函数 `θ̂_1/θ̂_w` 的基态敏感度的直接测量，不含任何注入簿记。这个干净读数给出的仍是 **−2.81 / −5.28**。

### 4.2 三层结论

- **通道移除是真的**（合同测试断言 + 冷态预算带命中双重确认），**预测没中**：负趋势的载体不是 A2-5 通道。§13.2 的"无其它主项"前提被实测证伪——存在别的东西携带了 ≥99.3% 的响应。
- **载体排除**：储热库重钉扎与面通量喂给是能量交换语义的两个极端，d_OP 差 ≤0.04 pp——**边界的能量交换语义整族被排除为载体**。这正是 PROJECT_CONTEXT 预注册的"「离散边界项主导」升级需在改进边界方案上复测"的复测，结论为**不升级**。
- **JAB/JAB2 归因的正确读法**（与 no-misread 规则一致，无矛盾）：A2-5=σ=1.000 是**生产算子上的导数块簿记事实**，从未是物理机制声明。本单元表明：生产壁上"A2-5 注入增益伪迹（朴素 −4.76/−9.09）+ A3 补偿"这对耦合块，与 faceflux 壁上"注入增益零位移 + 气侧响应位移"两种簿记，描述的是**同一个跨壁不变量**——气侧动态响应的基态位移 ≈ −2.8/−5.3。导数块分解依赖基点与壁语义；跨壁不变的才是物理内容。

### 4.3 机制窗口收窄（与既有杠杆排序一致）

各轴对 d_OP 的实测杠杆：**体相 ghost 扇区**（ghost 扫描：−47.5/−91.6 pp 每单位保留因子——唯一强杠杆）≫ **体相偏应力闭合**（1a DEVMEAS：缺口的 10.5%）≫ **边界能量交换语义**（本单元：0.5–0.7%）≈ 0；连续体相给正号（NSF）。三单元互洽指向：**载体在体相冷工况离散动力学，或两壁共享的行形状重置/u=0 钉扎操作**——后者是 wallfix 未覆盖的自由度（wallfix 只穷举了能量语义不变下的谱形/外推，本单元只换了能量语义不换形状重置）。

### 4.4 归档观察（不进分类）

相位位移 +0.26°/+0.50°（约为相位量的 19%）——faceflux 对相位的影响大于对幅值（0.9%/0.7%），方向朝零。(D1.76) 预估的面阻工作点通道 +0.25/+0.50 pp 未在幅值差中出现（实测 +0.03/+0.04 pp）——该一阶估算高估，实测已把此类子通道净效应约束在 0.04 pp 以下。

## 5. 含义与后续选项（不立项，用户决定）

- **对论文**：机理链的边界归因段须按 §4.2 第三条改写——"离散边界项主导"降级为"生产算子的导数块簿记"，跨壁不变量（气侧响应位移）上升为实测事实；候选 B 作为"疗法尝试的诚实失败 + 载体排除测量"入叙事（问题-解法路线的"解法"半边落空，但换来更强的定位数据）。
- **下一个有判别力的轴**（若继续）：分离 {形状重置/u=0} 与 {体相}。最便宜的设计：在候选 B 上做**形状重置消融**——保持面通量能量语义，把行重构从"平衡重塑+neq 混合"改为最小干预（只钉 u=0 或连形状都不动），看 d_OP 动不动；或体相侧沿 ghost 扫描的强杠杆深挖（τ<1 分支的稳定化）。
- 候选 B 的**生产化不建议**：它没修掉趋势，冷态还差 −2.4%——作为仪器保留（纯气侧响应读数是其独有价值），不作生产候选。

## 6. 口径约束（不可误判）

- 不把 `WALLFIX_NULL`(候选 B) 读作 **D1 推导错误**：推导证明的"通道移除"被合同测试与冷态预算带命中双重确认；被证伪的只是 §13.2 的"无其它主项"前提（该前提在 D1 内即明文标注为前提）。
- 不把本结果读作 **wallfix/JAB2 归因作废**：四不变量锁定与 σ=1.000 定位在各自口径下仍然成立；作废的是把导数块簿记**解读**为"边界问题"的那一步（本就被 no-misread 规则挡着，未曾正式声明）。
- 不把"载体在体相或形状重置"读作已定位：这是**窗口收窄**，二者未分离；升级需 §5 的消融轴。
- 冷态 −2.446% 是**诊断口径**合法性，不是生产认证；faceflux 壁无生产有效性声明，生产壁仍是唯一认证壁。
- smoke 网格的 −19.2% 冷态比值是浅 rig 介质色散污染，**不得**当作候选 B 的冷态代价引用；判决口径只认 auth。
- 不把 faceflux 与 PROD 的 d_OP 近同（≤0.04 pp）读作"两壁等价"：冷态绝对导纳差 −2.4%、相位差 0.3–0.5°，等价声明只限"有限温升 d_OP 趋势对能量交换语义不敏感"。
