## 1. 仪器构造与结构事实

- 一步算子 `F = H∘A∘B∘S∘C`，阶段函数逐字调用生产内部函数；`compose_collide≡collide_fg`、`direct_step≡solver.step`（含精确能量簿记）**逐位一致**由合同测试锚定（`test_phase5_wp4_jacobian_ablation.py` 14 项，A/B 双机绿）。
- C 拆三个消融块：A3=宏观恢复+平衡分布（`recover_macro`+`equilibrium_fg`）、A4=应力闭合（`_regularized_f_collision`+守恒矩修正）、A5=热流+能量修正（`_regularized_heat_flux_collision`+守恒矩修正+ΔG；ΔG 为精确线性泛函、零基态依赖=结构事实入测试）；B=热带+沉带两次 v1.1 对称质量中性重构；S/H 为精确线性映射直接作用。
- **A 阶段（声学相位修正族）在本 rig 结构恒等（实测断言，非外推）**：nx=8 使对角低模 0 合格模 + 高模因子 1.0 + spectral trace/pressure-memory 政策关闭——G2-O S6 同族结构事实在本几何独立重证（64×64 非退化对照在测试中必 raise）。A1 消融因此按构造 S≡0，转任第二阴性对照。
