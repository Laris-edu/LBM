### 3.1 能量通道线性（阶梯 5 点）与链验证

ε=0.001→0.10：Y/Yhs = 1.0488@+23.05° → 1.0504@+23.51°——跨 100× 幅值窗漂移 <0.2%/0.5°，生产壁在设计窗内幅值线性、无内生 DC/2f 质量源（对照旧壁 O(ε²) 机制的定量隔离=立门目的达成）。旧壁链验证：本 runner 测旧壁导纳 vs M3 权威值 **+0.18%/+0.10°**（探针链自洽）。

### 3.2 夹具行的仪器发现（首次尝试 FAIL 的判别与重设计）

首次尝试（pair ε=1e-3、settle 8）夹具底板 ~1e-7 > 门。**零成本窗口后移判别**（归档时序重拟合）：
2f 随窗衰减（5.2→2.1e-8）=**瞬态**（实测 τ=1.1 周期）；3f 平坦（2.8e-7）=**稳态**。稳态 3f 的性质由重设计 run 判定：
ε 1e-3→1e-4 后 3f **2.8e-7→2.77e-9（恰 ×100 = ε² 标度）**——是**真实三次物理**（C₃≈0.28；阶梯 ε=0.1 处独立支持 C₃≈0.18），
非边界伪影、非栈注入。原 ε=1e-3 的 1e-8 门门的是物理内容——fixture 设计缺陷，与壁无关。
重设计（ε=1e-4 杀物理 3f + settle 12 杀瞬态 2f）后四分量全落 ≤2.8e-9。
**附带仪器声明**：冻结栈（含缝×FFT 修正）的稳态非目标谐波注入底板被实测界定 **≤~6e-10（相对 1f）**——G2 谐波认证的底板输入。
