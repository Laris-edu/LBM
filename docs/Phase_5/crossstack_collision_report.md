## 1. 为什么做这个单元

投稿适配评估暴露的最大接受风险不是"缺疗法"，而是"只在自己一套栈上测过"：从 WP4-JAB → A2-5 定位 → wallfix 反证 → ghost 弛豫扫描，全部证据都出自同一个碰撞栈（`SMRT_central_Hermite_regularized_stress` + RR 闭合）。审稿人的第一问必然是"**这是普遍陷阱还是你们代码的特性**"。

1a 用最低成本回答其中一个轴：**换掉碰撞算子的结构，伪迹还在吗？** 不动的部分=生产壁（v1.1 对称质量中性壁）、canonical 帐篷几何、10 kHz、dx2p6、切线测量链、settle/drive 窗口；变的部分只有碰撞。

**BGK 的两个不可省前置**（计划书 §4）：

1. **同一个物理问题**：`(τ_f, τ_g)` 由冻结 mapping **解析导出、绝不调参**——CE 关系 `ν=θ_t(τ_f−½)`、`α=θ_t[(D+2)(τ_f−½)+S(τ_g−½)]/(D+S+2)` 反演得 `τ_f=0.5931915266`、`τ_g=0.6836851115`，使 `ν_lu`、`α_lu` 与生产逐位相同（`Pr=0.7061328707`），因而 `δ_T` 与 `H_s/δ_T=4.7124` 不变。
2. **守恒收尾**：τ_f≠τ_g 的双分布 BGK 本身**不守恒总能**（`E_post−E=(K−K_eq)(1/τ_g−1/τ_f)`），沿用生产同一约定（矩钉 + `δG·w_a` 总能钉）后逐 cell 精确守恒（实测 ≤1e-14），且 `δG` 一阶矩为零、不触碰任一热流通道。合同测试同时锚定 `bgk_relax` 的**精确线性**，故切线链按冻结链对精确线性映射的约定直接作用（不做有限差分）。

**冻结判读线**（写入 runner 常数区，先于任何变体数值）：活键 ≥1e-6（碰撞级）+ ≥1e-4（冷 |Y₀| 相对位移，计划书 §5）；auth 锚点 ≤0.2 pp vs 冻结 TAN；分类线 1.0 pp；稳定性 ρ(J) ≤ 1+1e-6；跨标定 caveat 于 30% |Y₀| 与 2% α_eff。失稳/非法变体按 A5 χ 端点先例记档剔除，仅锚点死亡才判整阶段 `LEGALITY_FAILED`。

**输运探针的仪器锚定**（新仪器不得自证）：注入 solver 的模衰减探针在 PROD 上对冻结 `measure_thermal_diffusion_direction` **逐位一致**（合同测试），且其 PROD 读数对**归档 G0 权威表**在标定波数 k=2π/64 上偏差 **4.46e-5**（A 机）/ **4.46e-5**（B 机）。

## 3. 1a-BGK：判决=生产工作点上无条件线性失稳

### 3.1 测量方式

在**无壁周期箱**上取均匀参考态（ρ_ref, u=0, θ_ref）——它是生产一步算子的不动点（残差 1.9e-15）——用中心差分构造一步线性化 Jacobian 并取谱半径 ρ(J)。`ρ(J)>1` 即碰撞算子本身的无条件线性失稳：**没有壁、没有几何、没有驱动幅值、没有基态梯度可供归因**。声学阶段在该几何上结构恒等（runtime assert，不外推 G2-O S6）。

生产参照：**ρ(J)=1.000000，越界模数 0**，四个守恒模精确落在单位圆（top |λ|=1.00000001/1/1/0.99999999，其后 0.95192506）。

### 3.4 帐篷 rig 上的原位确认

在生产 rig（v1.1 壁 + canonical 帐篷）上，BGK 在 **smoke（hs=12）与 auth（hs=48）两个网格、全部工作点**（Θ_DC = 0 / 0.05 / 0.10）的 settle 上都在数十步内死于壁行密度非正（`non-positive streamed wall-row density` / `blended non-equilibrium exceeds wall density`），smoke 行 A/B 两机一致。**先冷态、冷态即失稳**正是计划书 §3 回退路径规定的判定顺序。

两个仪器互相印证：A 机独立时序探针（同样是无壁周期箱，ny=32）显示扰动自**机器噪声量级**（u~1e-14）起几何增长，渐近因子 **≈2.0/步**，与 §3.2 的 Jacobian 谱半径 **2.0156** 相符。增长起自舍入噪声这一点排除了任何"幅值太大"的解释——**这是线性失稳的教科书签名**。

### 3.5 计划书 §3 回退路径的执行

计划书预先约定：冷态即失稳 → 记录失稳阈值、该失稳事实本身入报告、主路径切 1a-CFG；且**任何情况下不得**为让 BGK 稳定而调 dx / tau / 滤波强度。本单元严格执行：生产侧冻结量一个未动，只在 BGK 自身的 (τ_f, τ_g) 平面内搜索（§3.2/§3.3 两条支线即该搜索的完整记录），结论是该平面内不存在既复现生产 α 又线性稳定的点。

## 5. 判决与含义

> **状态：CFG 轴闭合后补全并升版。**

BGK 轴已可写死的一句：

> **在本栈的生产工作点上，最标准的碰撞算子不可用——不是调参不当，而是任何能复现生产热输运的 (τ_f, τ_g) 都线性失稳，且失稳发生在无壁的周期箱上，属于碰撞算子本身。**

这句话的方法学价值有两面，都必须同时写进论文：

- **对本工作的正面意义**：本栈使用的正则化闭合不是"额外的复杂度"，而是在 θ/θ_q≈0.069（dx 被选来把热层特征落到标定波数 k≈0.098 所强制的冷工作点）这一格子远离设计温度的工况下**唯一可跑的东西**；生产所处的"完全正则化极限"同时也是 ghost 扫描测得的**离连续解最近**的那一点（`ghost_relax_scan_report.md` §3）。
- **对声明范围的约束**：因此 1a-BGK **没有**给出"伪迹在 BGK 上也在"的正面跨栈证据，只给出"BGK 在此工况不可用"的负面方法学证据。跨栈普遍性的正面证据只能来自 §4 的配置轴（以及后续 1b/1c）。**不得**把 §3 写成"我们验证了伪迹的普遍性"。
