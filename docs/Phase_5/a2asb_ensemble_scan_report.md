## 3. 派生分解（登记数字的算术；Θ=0.05）

| 成分 | 大小 (pp) | 份额 | 来源 |
|---|---|---|---|
| 湿节点边界特有（判决 run 隔离） | −0.305 | ~11% | wet→strict 同系综差 |

| —— 其中动力学超额（0.423 pp/%=连续的 1.80×） | −1.024 | ~36% | 栈异常（对密度过强响应） |
| 合计 | −2.824 | ≈−2.826 ✓ | 闭合 0.002 pp |

对连续参照的异常总量（=判决 run 的 R_dyn^B）：`R_ens(m) ≈ −1.653 + 0.427·Δm%`（Θ=0.05）、`≈ −3.125 + 0.544×…`（Θ=0.10 同构）；即**异常=质量无关偏置（随 Θ 近线性，−1.65/−3.12 pp）+ 密度超额响应（连续的 ~1.8 倍）**两项。

## 4. 判读边界（预先写死的解释框架 + PARTIAL 语义）

- **成立的部分**：质量系综是原框架负趋势的**主承载**（份额 ~82%、五点线性至 0.03%、跨 Θ 斜率 0.4% 一致、符号可随质量反转、等质量点与切线框架 0.006–0.007 pp 和解）——`a2a_strict_b_report.md` §5.4 的跨框架算术观察升级为**同框架登记事实**。
- **被否定的前提**：计划把"静态族平坦"（≤20%）作为 CONFIRMED 要件；实测连续静态族自身携带质量斜率的 ~55.5%（六点常数）——轻柱导热低是真实系综物理，不是异常。**更尖锐的替代陈述**：异常=栈对基态密度的响应是同系综连续参照的 **1.80×**，加一项质量无关、随 Θ 增长的动力学偏置。
- `PARTIAL` 不是假说失败：三门是预注册的保守合取；主导性由前两门+报告行支撑，平坦门失败改写的是异常的**定语**（"静态不解释"→"静态解释一半、超额 1.8×"），不是主承载结论。
- 不可误判：本单元不授予 strict-B 科学资格、不改判决 run 的四级候选（仍待用户）、不改任何 Gate/生产壁；QS-1 的质量斜率是 strict-face Robin 家族的性质，不回写 wet 列（方案 §3.10 禁令仍然有效）；全部结果延续 G0-B 围栏语义（`G0_FENCE_PENDING_USER`）。
- 对 Paper 1 的含义（素材层，不激活分支）：定位句候选从"离散边界项主导"细化为"基态密度系综超额响应（~1.8× 连续）+ 次要边界项（~11%）+ 随 Θ 增长的动力学偏置"；正式采用待用户对判决 run 与本单元的裁决。
