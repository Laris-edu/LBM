## 5. 数据事实与口径守卫（不构成判决）

1. **负工作点趋势在单一边界替换下未消失**：四点 d_OP 全为负，幅值保留 wet 的 89.2–89.6%；相位签名（随 Θ 增长的负相位）同样保留。
2. **上移真实、一致、随 Θ 近线性**（+0.126→+0.570 pp，≈+5.7 pp/Θ_DC），方向与既有 archived 切线方向证据一致。
3. **动力学残差一致闭合 ~48–49%**：C_R 跨四点几乎常数（0.478→0.490）——boundary 替换移除了约一半的 R_dyn，但恰低于方案冻结的 0.5 线。
4. **不可误判：本结果与 2026-08-18 权威链 archived 切线数字（G0 分支 d_op −0.213/−0.247 pp）不矛盾，但也不可互换**——两者处于不同实验框架：切线链用 strict 原生等质量系综（M/A=ρ_ref·H_s）+ 气侧外推 Θ_DC；本单元按方案用 wet 质量匹配系综（M_wet(Θ)/A=47.53→45.75）+ 规定面温 Θ_DC（原 A2a 口径）。框架差把"strict 边界下的 d_OP"从 −0.2 量级移到 −2.5 量级（Θ=0.05）；**"负趋势 ~58–66% 随 band 删除消失"的 archived 方向证据不能转写到原协议框架**——原协议框架下的对应陈述是本表的 C_R≈0.48。
5. **strict QS-1 几乎为零（+0.06–0.33%）而 wet QS-1 为 +0.95–4.64%，是系综物理而非仪器缺陷**：方案 §3.8 强制 ρ̄=M_wet/H_s 与 ρ_b=p̄/θ_b 分层——k 随 T 升与 ρc_p 随 T 降在密封质量匹配柱内近抵消；wet QS-1 是均匀 ρ 的 α 形帐篷算子。按方案 §3.10，wet 列 R_dyn 冻结读 reference pack，禁止用新 QS 回算——C_R 的跨族比较是方案预注册的读法。
6. **QS-1k 在 strict-face 闭合内仍给正号且更大**（+2.4→+12.5%）：k 分辨静态重求值不能产生负号的结论（原 `MECHANISM_NOT_CLOSED` 结构）在 strict 边界框架下复现。
7. 本报告不授予 strict-B 科学资格、不激活热点分类、不改变任何 Gate/生产壁状态；既有四项 SCOPED 裁决不受影响。
