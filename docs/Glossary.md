# 术语对照表

**用途**：把项目里的行话翻成大白话，并标明每个词**是领域标准术语还是项目内部代号**——写论文时前者可直接使用，后者必须换成描述性说法或首次出现时定义。
**用法约定（2026-08-20 用户指令）**：领域标准术语一律用**英文原词**；项目内部起的外号一律换成**描述性说法**。
**维护**：新增术语或改口径时同步本表；数值与结论仍以各权威文档为准，本表不承载数据。

---

## 1. 边界与几何

| 词 | 大白话 | 性质 | 定义处 |
|---|---|---|---|
| **wet node**（湿节点） | 壁面**就落在格点上**：那一层格子既是壁又是流体，有体积、有质量、有热容，每步把温度重新钉成壁温 | 领域标准（Krüger 等教科书第 5 章的边界两分法之一） | 生产壁实现=`boundary/wall_thermal_mass_neutral.py` |
| **link-wise**（链式） | 壁面落在**格点之间**，没有任何格子属于壁——壁是几何面，零体积零热容 | 领域标准（wet node 的对立类） | 严格 B 属此类 |
| **face-flux wall**（零体积面通量壁，代号 strict-B） | 本项目的 link-wise 实现：壁是第一层气体格心外半格处的面，只按"面温与第一层气体温度之差"往气体注热 | 项目内部 | `boundary/wall_face_flux_strict.py` |
| **band**（壁面行） | wet node 壁占据的那一行格子 | 项目内部 | 同上 |
| **上下对称的双柱几何**（旧称 tent / 帐篷 rig） | 计算域上下贯通，最上一行是热壁、正中一行是恒温冷壁；等于把两根"热壁→气体→冷壁"的柱子背靠背拼起来共享壁。温度剖面画出来像三角形帐篷，故得外号 | **项目外号**——论文里写"双柱对称镜像几何" | `scripts/phase5_g4a_dc_basestate.py` |
| **mirror extension**（镜像延拓） | 严格 B 的做法：每步临时把半个计算域按镜像补成整域再做周期运算，算完丢掉；镜像部分不占质量能量 | 项目内部 | `core/strict_b_half_domain.py` |
| **H_s** | 热壁到冷壁的距离（气柱高度）。主线取 48 格 ≈ 4.61 倍热渗透深度 | 项目内部 | 合同 §（热沉几何） |
| **Level A / B / C** | 壁面给什么条件：A=给定壁温；B=给定壁面热流；C=热流由模拟算出、壁温由薄膜方程解出（真耦合） | 项目内部 | `docs/Phase_3/phase3_instruction_v1.0.md` §2.4 |

## 2. 基态与协议

| 词 | 大白话 | 性质 | 备注 |
|---|---|---|---|
| **ensemble**（系综） | **腔里气体总量按什么规则确定**——即哪个宏观量被钉死来定义"同一个状态" | 标准词（借自统计力学），但项目里特指气体总量约束 | 两种壁都不改质量，故它只由初始化决定 |
| **equal-mass ensemble** | 不论预热多少，总量都归一到"参考密度 × 柱高" | 项目内部 | 严格 B 权威链用此 |
| **isobaric-seeded ensemble** | 初始化让压力沿柱均匀 → 预热后气体自动变少（精确等于冷态质量 × 对数均值因子） | 项目内部 | 原 A2a 权威 run 用此 |
| **单位面积柱质量**（M/A） | 每单位薄膜面积上驮着多少气体（面质量密度，国际单位 kg/m²）。格子单位下"48"= 48 格高的柱子全处在参考密度 | 项目内部 | 上下双柱几何要除以 2 |
| **Θ_DC**（预热程度） | 壁面平均温度比环境高百分之几（**按规定面温定义**，不是气侧外推温度） | 项目内部 | 主网格 0 / 2% / 5% / 7.5% / 10% |
| **ε_AC**（驱动幅值） | 壁温正弦波动的幅度占参考温度的比例 | 项目内部 | 判决用 2%，冷锚与线性审计用 0.5% |
| **settle / drive** | 先让基态弛豫到稳定（5 个周期）／再加正弦驱动（4 个周期） | 项目内部 | 拟合窗跳过前 2 个周期 |
| **LU**（lattice units，格子单位） | 模拟内部的无量纲单位：格距=1、时间步=1、参考密度=1 | 领域标准 | 换算入口=`core/unit_mapping.py` |

## 3. 观测量

| 词 | 大白话 | 性质 |
|---|---|---|
| **admittance**（热导纳，Y） | 单位壁温波动激起多少热流响应（复数：有幅值也有相位） | 领域标准 |
| **d_OP**（工作点趋势） | 预热后的 admittance 相对冷态变了百分之几。**本项目的核心观测量** | 项目内部 |
| **R_dyn**（动力学残差） | 实测 d_OP 减去准静态参照预测的 d_OP，单位是"百分点" | 项目内部 |
| **C_R**（闭合率） | 换边界后残差缩小了几成；带上不确定度的保守版记作 C_R⁻ | 项目内部 |
| **stationarity**（平稳性） | 最后一个 settle 周期里温度剖面还在漂多少——判断基态收敛没收敛 | 项目内部 |
| **DC closure**（能量闭合） | 稳态下热壁进的热量与冷壁出的热量是否抵消 | 项目内部 |
| **h2**（二次谐波含量） | 响应里混进了多少二倍频成分——衡量非线性程度 | 领域标准 |
| **pp**（百分点） | 两个百分数之差的单位。"从 −2.8% 到 −2.5%"= 移动了 0.3 个百分点 | 通用 |

## 4. 参照族（拿什么当"正确答案"）

| 词 | 大白话 | 性质 |
|---|---|---|
| **quasi-static（QS，准静态）参照** | 假装每个瞬间都是稳态、重算一遍导纳。分三级：**QS-0** 用一个平均系数；**QS-1** 用实测的沿高度分布；**QS-1k** 再加上"输运系数随波数变"的实测表 | 领域标准概念，分级是项目内部 |
| **NSF**（Navier–Stokes–Fourier） | 完整的连续介质方程（质量+动量+能量），本项目用它的线性化频域解当动力学参照 | 领域标准 |
| **1D-lbm-equivalent** | 连续参照的一支：输运律取"模拟自己实测出来的有效物性"，用来把壁的问题和介质的问题分开 | 项目内部 |
| **1D-physical** | 连续参照的另一支：输运律取真实空气 | 项目内部 |
| **Robin 边界条件** | 第三类边界：热流正比于"壁温与邻近流体温度之差"。零体积面通量壁就是这种形式 | 领域标准 |

## 5. 数值内核

| 词 | 大白话 | 性质 |
|---|---|---|
| **D2Q37** | 二维、每个格点 37 个离散速度方向的格子模型（高阶，能做可压缩热流动） | 领域标准 |
| **relaxation time（τ，弛豫时间）** | 碰撞把分布拉回平衡的快慢。**它固定不变，就导致导热系数正比于密度**——本项目根因所在 | 领域标准 |
| **BGK / MRT / RR / 正则化** | 碰撞算子的几种做法：单一弛豫／多弛豫／递归正则化。生产用的是正则化多弛豫 | 领域标准 |
| **ghost modes**（鬼模态） | 超出物理量（密度、动量、应力、热流）之外的高阶矩，其弛豫参数可自由调 | 领域标准 |
| **dx2p6** | 主线网格代号：格距 2.61 微米、时间步 1.96 纳秒（10 kHz 空气热层的标定点） | 项目内部 |
| **thermal penetration depth**（热渗透深度） | 温度波在气体里能渗多深，10 kHz 空气约 26.6 微米 | 领域标准 |

## 6. 耦合与器件

| 词 | 大白话 | 性质 |
|---|---|---|
| **thermophone**（热声换能器） | 靠周期加热空气发声的器件，无振动部件。本项目的问题来源与 benchmark | 领域标准 |
| **C_A**（面热容） | 薄膜单位面积的热容量。基线 CNT 膜取 7×10⁻⁴ J/(m²·K) | 领域标准 |
| **χ₀ / χ_eff** | 薄膜热容与气体导热能力的比值（无量纲）：小=气体说了算，大=薄膜说了算。基线约 0.016 | 项目内部 |
| **film ODE**（薄膜方程） | 描述薄膜温度随加热功率和散热变化的常微分方程 | 领域标准 |

## 7. 流程与治理

| 词 | 大白话 |
|---|---|
| **Gate（G0…G5）** | 必须逐个通过的验收门：G0 物理模型闭合、G1-W 壁面中性、G1a 幅值包络、G1b 耦合包络、G2 谐波链、G3 一维参照仪器、G4a 稳态基态、G5 完整二维（已豁免） |
| **WP0…WP4** | 工作包（合同冻结→仪器→入口门→决策→生产子矩阵） |
| **M2 / M3 / M4** | 里程碑验收（气体核／近壁热物理／远场声学） |
| **smoke / auth** | 小规模机制演练／正式权威 run |
| **checkpoint** | 断点续跑存档（逐算例、逐周期），防断电和被系统杀进程 |
| **digest / provenance** | 结果指纹／出身记录（机器、commit、时间、参数），保证可追溯 |
| **预注册（pre-registration）** | 判据必须在看到热数据之前就冻结进代码并提交，杜绝事后调门槛 | 
| **D0-x / D5-x** | 合同级决策／Phase_5 用户决策的编号 |
| **SCOPED_PASSED_BY_USER** | 带围栏的有条件通过，只能由用户批准并留档；脚本不得自行作出 |

## 8. 诊断单元代号（按时间）

| 代号 | 做了什么 | 结论一句话 |
|---|---|---|
| **WP4-TAN** | 切线响应诊断 | 负趋势不是有限幅值造成的 |
| **WP4-JAB / JAB2** | 把响应按算子导数块拆解 | 承载在"壁面重钉扎的基态密度敏感度"和"密度交叉族"两块 |
| **NSF 仲裁** | 连续介质能否复现负号 | 不能 |
| **wallfix** | 在不变量内改壁能否修好 | 不能（范式内不可修） |
| **ghost relax scan** | 调鬼模态弛豫参数能否修好 | 双向失败 |
| **crossstack 1a** | 换碰撞算子还在不在 | 还在 |
| **D1-B buffer 代理** | 保留壁面行、只去掉显式储能项 | 几乎没动（0.03 个百分点） |
| **strict-B** | 删掉壁面行、改零体积面通量壁 | 与原基线的比较**同时换了气体总量约束**，读数被混合 |
| **A2a-STRICT_B** | 保持原协议只换边界 | 边界只占约一成 |
| **ensemble scan** | 固定边界只扫气体总量 | 总量是主承载；加够气体负号翻正 |
| **offset lenses** | 剩下那块偏置归谁 | 超出连续动力学，指向贴壁动理学层 |

## 9. 已废弃 / 易误用的说法

| 别再用 | 改用 | 原因 |
|---|---|---|
| 湿系综 / 湿协议 | **isobaric-seeded ensemble**（等压播种的气体总量约束） | 气体总量与壁是"湿"是"干"无关，只由初始化决定 |
| 湿 run | **原 A2a 权威 run** | 更准确指代那四个算例 |
| 帐篷 rig | **上下对称的双柱几何** | 项目外号，外人看不懂 |
| "k∝ρ 是我们的发现" | "该性质在本格子模型的源头论文已写出；我们量化的是它在密封有限温升协议下的符号级后果" | 文献核查坐实（`literature_check_constitutive_v1.md`） |
| "没人做过 X" | "在已检索范围内未发现 X" | 否定性存在断言必须带检索范围限定 |
